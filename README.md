# make-photo
After Ansel Adams ("You don’t take a photograph, you make it"): haul 8×10 plates by burro or woody roof-deck and sculpt living worlds across 11 tonal zones.

## Pack Donkey

`donkey/` is a standalone, drivable 3D pack donkey (procedural skinned model, foot-planted walk and trot). Open `donkey/index.html` from a web server, or `/donkey/` on GitHub Pages.
